# QuantMath — Phase 1

An interactive, visual learning app for the mathematical foundations of quantitative finance.

## Included

- Eight Phase 1 topics: order of operations, fractions, decimals, percentages, ratios, negative numbers, exponents, and roots
- Interactive visual labs and beginner-friendly quant calculators
- Local progress, mastery, and review tracking
- A 30-question mixed Phase 1 diagnostic

Built with Next.js, TypeScript, React, Tailwind CSS, and localStorage.
